## 这份指南适合谁？

如果你正在搭建一个需要长期维护的 Vue 3 产品，这份文档会从仓库初始化、目录设计一路讲到 GitHub Actions 发布。每个章节都对应仓库里的真实配置，读者可以边看边运行。
